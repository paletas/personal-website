# personal-website

The personal site of João Silvestre: ASP.NET Core 10 Razor Pages, Tailwind CSS, English and Portuguese, no ads and no cookies. Anonymous usage stats come from self-hosted Umami (`stats.itssilvestre.com`, loaded only when `Analytics__WebsiteId` is set) and Cloudflare Web Analytics.

Version 2.2.0.

## Analytics

The Umami snippet renders only when config key `Analytics:WebsiteId` (env `Analytics__WebsiteId`) is non-empty, is restricted by `data-domains` to itssilvestre.com and joaosilvestre.com (with www), is disabled for a browser with `localStorage.setItem('umami.disabled','1')`, and tracked events are `outbound` (target psy|f1|github|linkedin, place nav|nav_mobile|card|footer|contact) and `lang_switch` (to en|pt).

## Requirements

- .NET 10 SDK (see `global.json`)
- Node 20+

## Build and run

```
cd src/Silvestre.App.Web
npm ci
npm run build:css
dotnet run -c Release --urls http://localhost:5080
```

## Tests and CI

```
dotnet build Silvestre.sln -c Release
```

The `pr-check` workflow builds the production image and runs a smoke test against the running site on every pull request.

## Content

Everything the site says lives in `src/Silvestre.App.Web/Content/`: `{en,pt}/site.json` and `{en,pt}/ai.md` per language, plus the shared `stack.json` and `writing/` posts.

## Images

`npm run images` (in `src/Silvestre.App.Web`) regenerates the 240, 400 and 680 px profile variants from `wwwroot/img/profile-960.webp`. The 480 and 960 files are committed as they are.

## Docker

The container setup is in `build/docker`. The published image is `ghcr.io/paletas/personal-website`.

## Projects content

- Short project overviews live in `src/Silvestre.App.Web/Content/projects/{en,pt}/<slug>.md` (front matter `title, tagline, order, kind`, then 2-3 sentences, plus a diagram for PlanAhead) and are rendered on the single `/projects` page. Missing language or facts entry fails start-up.
- `Content/projects/facts.json` holds status, stack and last-active month and is generated by the hub skill `showcase-refresh`, never edited by hand for prose.
- `bash tools/deny-scan.sh <files>` is the leak scan run locally, in CI and by the skill, and exits 1 on a hit.
- Stack lists are curated by hand in `Content/projects/stack.json`. The `showcase-refresh` hub skill copies them into `facts.json` and fills `status` and `lastActive` from `repos.yml` and git. Edit `stack.json`, never the `stack` arrays in `facts.json`.

## Telemetry (OpenTelemetry)

The site exports request-level metrics (HTTP server request count and duration by method, route template and status, outbound HTTP client metrics, and .NET runtime metrics) over OTLP/HTTP. It is enabled only when `OTEL_EXPORTER_OTLP_ENDPOINT` is set (for example `http://192.168.1.11:4318`); with it unset no exporter starts. `service.name` is `personal-website`; set `OTEL_RESOURCE_ATTRIBUTES=deployment.environment=prod` (or `beta`, `dev`) in the environment. Only metrics are exported, and attributes are limited to an allow-list (method, status code, route template, scheme, protocol): no query strings, client IPs, user agents or URLs. Visitor analytics belong to Umami, not here. `GET /health` returns 200 for probes.
