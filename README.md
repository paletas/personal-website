# personal-website

The personal site of João Silvestre: ASP.NET Core 10 Razor Pages, Tailwind CSS, English and Portuguese, and no third-party requests.

Version 2.0.0.

## Requirements

- .NET 10 SDK (see `global.json`)
- Node 20+

## Build and run

```
cd src/Silvestre.App.Web
npm ci
npm run build:css
dotnet run -c Release --urls http://localhost:5080
```

## Tests and CI

```
dotnet build Silvestre.sln -c Release
```

The `pr-check` workflow builds the production image and runs a smoke test against the running site on every pull request.

## Content

Everything the site says lives in `src/Silvestre.App.Web/Content/`: `{en,pt}/site.json` and `{en,pt}/ai.md` per language, plus the shared `stack.json` and `writing/` posts.

## Images

`npm run images` (in `src/Silvestre.App.Web`) regenerates the 240, 400 and 680 px profile variants from `wwwroot/img/profile-960.webp`. The 480 and 960 files are committed as they are.

## Docker

The container setup is in `build/docker`. The published image is `ghcr.io/paletas/personal-website`.

## Projects content

- Short project overviews live in `src/Silvestre.App.Web/Content/projects/{en,pt}/<slug>.md` (front matter `title, tagline, order, kind`, then 2-3 sentences, plus a diagram for PlanAhead) and are rendered on the single `/projects` page. Missing language or facts entry fails start-up.
- `Content/projects/facts.json` holds status, stack and last-active month and is generated by the hub skill `showcase-refresh`, never edited by hand for prose.
- `bash tools/deny-scan.sh <files>` is the leak scan run locally, in CI and by the skill, and exits 1 on a hit.
- Stack lists are curated by hand in `Content/projects/stack.json`. The `showcase-refresh` hub skill copies them into `facts.json` and fills `status` and `lastActive` from `repos.yml` and git. Edit `stack.json`, never the `stack` arrays in `facts.json`.
