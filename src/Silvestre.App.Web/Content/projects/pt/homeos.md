O HomeOS é uma pequena aplicação web auto-alojada que reúne a gestão diária de uma casa num só sítio. Receitas, despensa, plano semanal de refeições e lista de compras partilham um único catálogo de ingredientes, por isso os ingredientes de uma receita vão para a lista com um clique, e funciona em inglês e português. Mantém os dados em casa e é pequena o suficiente para ser compreendida de ponta a ponta.
